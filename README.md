# Doctor Appointment Booking System

A modern and responsive Doctor Appointment Booking application developed using React and JavaScript. This project helps patients book appointments with doctors easily through an online platform.

## 🚀 Features
- Doctor listing
- Appointment booking
- Responsive user interface
- Simple navigation
- Interactive dashboard

## 🛠 Technologies Used
- React
- JavaScript
- HTML
- CSS
- Chart.js
